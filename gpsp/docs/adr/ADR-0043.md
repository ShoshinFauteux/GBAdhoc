# ADR-0043: A flight recorder for the exit-Union-Room fatal error

- **Status:** current (dump trigger widened by [ADR-0052](ADR-0052.md); timestamps added by [ADR-0045](ADR-0045.md))
- **Date:** 2026-08-03
- **Source:** Reconstructed. No ADR text exists; rebuilt from the commit message of `2c3f8ec7` (written with the change) and the code comments in `rfu.c`.

## Decision

Record every command the game sends to the emulated GBA Wireless Adapter
(RFU, the adapter's protocol) in a 512-entry ring, with the adapter state and
the emulated frame it arrived on. Dump the ring when the adapter is reset out
of a live session, which in the field only happened after the game had
already declared a fatal link error.

## Why

Three explanations for the fatal "exit Union Room" screen had been proposed
and each was disproved on hardware: delivery bunching, poor link quality,
and frame-rate divergence between the two consoles. Instead of a fourth
theory, the project chose to record what the game actually did. The trigger
needs no game-specific memory addresses, so it works on any ROM revision.

Two problems were found while gating it: one log line per entry lost 228 of
1024 entries to the event queue (now 8 entries per line, and the gate asserts
none are lost), and a clean exit also dumps, which turned out to be a useful
healthy-exit control transcript.

## Where in the code now

- `gpsp/rfu.c` — the ring (`RFU_FLIGHT_N`, `RFU_FLIGHT_REC`, `rfu_flight_dump`) and the frame counter `rfu_frame_no`.
- `gpsp/psp/fe/link.c.inc.c` — the PSP side of the dump hook.
- `gpsp/sdl/main_sdl.c` — the desktop test build's side.

## Notes

The dump writes to the Memory Stick from the emulation thread, which the
project otherwise forbids. The commit accepts this on purpose: the session is
already dead, so there is no frame timing left to protect.
