# ADR-0079: Exit-echo state assist (`rfu_exit_assist`)

- **Status:** current (on in player builds: `PLAY_EXIT_ASSIST = 1`)
- **Date:** 2026-08-09 (commit `c92d8f4c`); validated on hardware per the comment in `psp/fe/play_defaults.h` (run 317, re-confirmed 2026-08-10)
- **Source:** Reconstructed from the commit message of `c92d8f4c` and code comments in `psp/fe/link.d.inc.c`, `psp/fe/boot.inc.c`, `psp/fe/play_defaults.h` and `frontend-common/fe_host.c/.h`.

## Decision

When the exact "lost echo" state can be proven from guest RAM, write the one
byte the missing echo would have written: `sPlayerLinkStates[local] =
EXITING_ROOM`. The state is: the game's key callback is
`KeyInterCB_WaitForPlayersToExit` (a Thumb address unique to this ROM, which
also acts as the game check), the local player is BUSY, the peer is EXITING,
and the game's keepalive watchdog is at 45 or more of 61. The game then runs
its own negotiated exit. Add `fe_host_mem_write()` (RAM only; ROM writes
refused) for it.

## Why

The death snapshot ([ADR-0078](ADR-0078.md)) was byte-identical in three
runs: the joining console had processed the host's exit key but its own
key's echo never came, and the 61-frame keepalive watchdog killed a live
link. Over the real radio the echo completes inside the host's same
exchange; over Wi-Fi the host's game moves on first and stops relaying. No
watchdog budget can fix an echo that is never sent. If the assist is wrong
the result is the previous behaviour.

## Where in the code now

- `gpsp/psp/fe/link.d.inc.c` — "THE EXIT-ECHO STATE ASSIST".
- `gpsp/frontend-common/fe_host.c`, `gpsp/frontend-common/fe_host.h` — `fe_host_mem_write()`.
- `gpsp/psp/fe/boot.inc.c`, `gpsp/psp/fe/play_defaults.h` — key and default.

## Notes

The boot code records a later bug: the key's default had been hardcoded to
0, which silently left the player build without the fix despite
`PLAY_EXIT_ASSIST = 1`. It now defaults to `PLAY_EXIT_ASSIST`. This is a
game-specific patch; [ADR-0076](ADR-0076.md) is the general mechanism it
works alongside.
