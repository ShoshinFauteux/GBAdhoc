# ADR-0073: The speed profile's session rate is 57.00 fps, not the native 59.73 fps

- **Status:** superseded by scheduled adapter ticks (commit `65d17a98`, 2026-11-02): speed-profile sessions now run at the GBA's 59.73 fps. The 57.00 constant remains in `PCFG_PROFILE_FPS_X100`.
- **Date:** unknown; first committed 2026-08-09 in `276e4450`
- **Source:** Reconstructed from the comment above `PCFG_PROFILE_FPS_X100` in `psp/config_psp.h`, the handover (HANDOVER.md §2 at `dba5e900`) and commit `65d17a98`.

## Decision

While a wireless session is live, the speed profile ([ADR-0071](ADR-0071.md))
clamps both consoles to 57.00 fps. Single-player is unaffected.

## Why

Emerald stops reading the client's buttons when its receive queue is more
than 4 deep, and that queue only exists on the client
([ADR-0072](ADR-0072.md)). At 59.73 the host reached about 59.4 fps and the
client about 56.6; the session pacer only caps a fast console and cannot
lift a slow one, so the host filled the client's queue. Measured over 100+
scripted runs on two consoles (code comment):

| target | trades | client failed to reach its seat |
|---|---|---|
| 59.73 | 21/45 = 0.47 | 17/45 |
| 55.00 | 15/25 = 0.60 | 5/25 |
| 57.00 | 13/13 = 1.00 | 0/13 |

Lower is not automatically safer: delivery clumping rises as the rate falls,
and 53.00 was worse than 55.00. The handover stresses that 57.00 worked
around the client's speed deficit and was not a finding that slower is
better; it also notes the arms were run in blocks and 57.00 rests on 13 runs.

## Where in the code now

- `gpsp/psp/config_psp.h` — `PCFG_PROFILE_FPS_X100` and this ADR's comment.
- `gpsp/psp/fe/boot.inc.c` — the lift to `PACE_NOMINAL_X100` when `rfu_sched > 0` (default 2), unless the compatibility profile or `net_session_fps_force` is set.
- `gpsp/docs/RFU-COUPLING.md` — the ticks design.

## Why it was superseded

With scheduled ticks neither console starts a frame without the other's
tick for it, so the pair runs at the slower console's rate and a host can no
longer outrun its client.
