# ADR-0062: Give the Wi-Fi stack CPU time (thread priorities, polling, ARQ timers)

- **Status:** current, except the first lever (`adhoc_net_prio`), which failed and was removed in `4c0dcdcc` (2026-11-16)
- **Date:** unknown; first committed 2026-08-09 in `276e4450`
- **Source:** Reconstructed from code comments in `psp/fe/boot.inc.c`, `psp/fe/iothread.inc.c`, `rfu.c`, `netdrv/transport_adhoc.c` and `frontend-common/netpacket_host.c`, and the handover summary (HANDOVER.md §4.2/§4.4 at `dba5e900`). Sub-records b-e were only ever code comments.

## Decision

A family of changes about which thread gets the CPU the emulator is not using.
On the PSP a numerically lower priority runs first.

- **ADR-0062:** the emulated core cost about 14.5 ms per frame at every
  session rate, so the idle time the Wi-Fi driver lives in fell from 17.6
  ms/frame at 29.97 fps to 2.3 ms at 59.73 (code comment). Two test-build
  levers: raise the ad-hoc stack's priority (`adhoc_net_prio`), and override
  the transport's retransmit timers (`nd_rto_first_max_us`, `nd_rto_min_us`).
- **ADR-0062b:** lower the emulation thread instead (`emu_prio`, player
  default 0x2B, below the stack's 0x2A). Raising the stack to 0x1D had broken
  ad-hoc group creation on the host. The handover calls `emu_prio` "the
  single biggest win, 0/40 to 16/34"; the ADR-0065 comment records srtt
  680 to 20 ms and retransmissions 27 % to 0 %.
- **ADR-0062c:** `io_prio` (player default 0x2C) keeps our own log/save
  thread below the emulator, which `emu_prio` had accidentally put above it.
  Measured cost of that accident on the join: core 13871 to 18819 us/frame.
- **ADR-0062d:** `rfu_poll_min_cycles` (player default 34952, about 1/8 frame)
  limits how often a waiting client polls the radio. The join polled 587 times
  per frame, which cost 855 us/frame once the stack was actually scheduled.
- **ADR-0062e:** the harness file's `core_phase` key was never read (only
  `config.ini`'s was), so profiler on/off in tests was decorative. It is now
  read; the profiler costs about 344 timer reads per frame.
