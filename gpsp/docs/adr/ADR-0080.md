# ADR-0080: Bring up the Media Engine; offload video staging to it

- **Status:** current. The bring-up pattern underlies the Media Engine renderer and the other kernel modules. The Stage-1 staging offload (`me_video`) now runs only when the ME renderer (`me_mode`) is off, which is not the player default.
- **Date:** 2026-08-09 (commits `08e3a439`, `11d3963b`, `97bd62f0`, `63786ed5`, `58249757`, `99ba74e5`)
- **Source:** Reconstructed from those commit messages, the handover (HANDOVER.md §0.0 at `ed75e535`) and code comments in `psp/me/`, `psp/me_host.c` and `psp/fe/merend.a.inc.c`.

## Decision

Use the PSP's second CPU core, the Media Engine (ME). A kernel module
(`gbadhoc_me.prx`) loaded at run time boots the ME into a mailbox
dispatcher. Two deliberate rules: the module exports no functions (it is
parameterised through its start arguments and the mailbox), and no function
pointers cross the boundary (every ME job is `ME_CMD_*` code inside the
module). The mailbox is 64-byte-aligned main RAM that both cores touch only
through the uncached `0x40000000` alias; that is the whole cache-coherency
contract. A failed 250 ms boot handshake or a watchdog trip falls back to
single-core, never an error.

Stage 1 (`me_video`): the ME does the per-frame copy of the GBA frame into
the GPU's 512-pixel-stride staging texture; on a collision the frame is
dropped, and the network pace never waits.

Measured (handover): staging cost on the main CPU 751 to 0 us/frame; three
join-only runs, 37,200 frames, 0 drops, 3/3 verified trades.

## Sub-records

- **0080a** (`11d3963b`): the idle dispatcher polled the mailbox flat out with uncached accesses and saturated the memory bus the Wi-Fi DMA shares (srtt 17 to 44 ms, a failed trade). When idle, spin on a cached local and poll about every 50 us. The spin count (4096) assumed ~4 cycles a pass; the compiled pass costs ~14, so until 5.1.0 the real period was ~173 us at 333 MHz (measured on hardware, and the period the Wi-Fi fix was validated at). 5.1.0 sizes it for a real ~50 us (1184) and stores the heartbeat every 32nd idle poll, which keeps idle bus traffic near the 173 us level.
- **0080b** (`97bd62f0`): the watchdog checked completion in the same frame it posted the job, so it always saw "busy" and killed the offload after 8 frames. Count a miss at the next frame; the host watchdog is heartbeat-only.
- **0080c** (`63786ed5`): `me_video` on the host broke ad-hoc session creation (`np_start`). Activate the offload only while a session is live; re-arm per session.
- **0080d** (`58249757`): the real cause was the 242 KB allocated at boot starving the host's `np_start`. Allocate at session-up. The same commit turned `me_boot`/`me_video`, the exit assist and frame pace on for players. Later applied to the renderer: the ME engine suspends around wireless bring-up (`psp/fe/display.b.inc.c`).
- **0080e** (`99ba74e5`): drop the second core frame buffer (no overwrite race exists); 242 KB to 165 KB, so the host can offload too.
