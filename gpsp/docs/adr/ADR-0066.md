# ADR-0066: Make the screenshot marker-file poll a knob, and price it

- **Status:** retired; superseded by [ADR-0069](ADR-0069.md), removed from code in `4c0dcdcc` (2026-11-16)
- **Date:** unknown; first committed 2026-08-09 in `276e4450`
- **Source:** Reconstructed from code comments in `psp/main_psp.c` at `276e4450` and the removal commit `4c0dcdcc`.

## Decision (as made)

The main loop checked once a second whether a marker file existed
(`log/dump_frame`) so a person could request a screenshot mid-run. Make the
interval a test-build key (`dump_marker_poll`, frames between polls, 0 =
never), turn it off in player builds, and take four timed samples of the
file lookup at boot (`EVT msstat`) to measure its cost.

## Why

An earlier investigation of frame-time spikes listed this synchronous
negative Memory Stick lookup, made inside the timed part of the frame, as a
suspect, but its cost on the device had never been measured.

## Outcome

The lookup cost 12.4 ms per call (handover §4.4 at `dba5e900`). ADR-0069
replaced the marker file with a button chord and set the default to 0. The
key, the boot samples and `PLAY_DUMP_MARKER` were deleted in `4c0dcdcc`.
