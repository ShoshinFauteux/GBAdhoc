# ADR-0078: Backpressure session pacing (`net_pace_match = 3`)

- **Status:** current as an opt-in mode; not the default (`net_pace_match` defaults to 1, fixed rate). No record of a result was found.
- **Date:** 2026-08-09 (commit `dd21647c`)
- **Source:** Reconstructed from the commit message of `dd21647c` and code comments in `psp/ff_psp.c`, `psp/config_psp.c`, `netdrv/netdrv.h` and `psp/fe/boot.inc.c`.

## Decision

Add a fourth session-pacing mode. It is the fixed-rate clamp of ADR-0033
(in `../DECISIONS.md`) with a floating base, driven by the live depth of the
reliable transmit backlog toward the peer (`fe_np_txq_now()`, ring plus
spill). Per pacing window (about 1 s), asymmetric: a backlog of 6 or more
lowers the base by 0.50 fps at once (floor 55.00); a backlog of 1 or less
for 3 windows in a row raises it by 0.25 (ceiling 59.73). Host only: a
joining console set to 3 behaves as plain fixed rate. Every move is logged
as `pace_bp`, with hold lines about every 10 s ([ADR-0058](ADR-0058.md)).

Also in this change: `net_pace_match` became overridable from the harness
file (a test arm had silently run mode 1 because the key was `config.ini`
only), and the exit "death snapshot" gained the game's `readyCloseLink[]`.

## Why

The live backlog measures directly how much the peer is absorbing, where the
older adaptive matcher (ADR-0027) estimated it with a moving average, which
is why that matcher hunted. Only the host adapts because one adapting
console cannot hunt against a fixed one, and the client's queues exist only
on the client. Falsifiers stated with it: oscillation without a change in
conditions (hunting), or a base parked at backlog 0 (uninformative).

- `gpsp/psp/ff_psp.c` — `pace_bp_window()` and the mode.
- `gpsp/psp/config_psp.c` — the key range 0-3.
- `gpsp/netdrv/netdrv.h`, `gpsp/netdrv/netdrv.c`, `gpsp/frontend-common/netpacket_host.c/.h` — `txq_now`.
- `gpsp/psp/fe/boot.inc.c` — the harness override; `gpsp/psp/fe/link.d.inc.c` — `g_rfu_down_rcl` in the snapshot.

## Notes

The snapshot's finding (the join dies waiting for the echo of its own exit
key) led to [ADR-0079](ADR-0079.md). Scheduled adapter ticks
([ADR-0073](ADR-0073.md)) later removed the rate mismatch this mode targets.
