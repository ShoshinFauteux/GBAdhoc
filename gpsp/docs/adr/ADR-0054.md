# ADR-0054: Every log carries the identity of the build that wrote it

- **Status:** current
- **Date:** unknown; first committed 2026-08-09 in `276e4450`
- **Source:** Reconstructed from code comments in `psp/fe/boot.inc.c` and `tools/ab_compare.py`. No ADR text was found.

## Decision

Write `EVT build stamp=<__DATE__>_<__TIME__>` at the top of every event log,
and make the A/B comparison tool treat the build as part of an experiment
"arm".

## Why

Runs had been grouped into A/B arms by their configuration line. That
silently mixed three different builds that shared a configuration into one
arm. A run must carry its own build identity or the arm is not an arm. The
compiler's date and time change on every rebuild and cost nothing at run
time.

## Where in the code now

- `gpsp/psp/fe/boot.inc.c` — the `build stamp` event.
- `gpsp/tools/ab_compare.py` and `harness-kit/ab_compare.py` — grouping by build.

## Notes

In a player build the event log is compiled out ([ADR-0067](ADR-0067.md)),
so the stamp only appears in test builds.
