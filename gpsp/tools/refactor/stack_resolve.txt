# stack_resolve.txt -- reviewed indirect-call targets and prunes for stack_depth.py (T12)
# Format:  caller  callee[,callee...]  sites=N  # evidence   (resolves EVERY jalr/jr in caller)
#          caller  -  sites=N                    # evidence   (the indirect sites make no call)
#   sites=N is REQUIRED: the caller's jalr + jr(rX != ra) count when the line was reviewed.  A
#   different count in an ELF (a new function-pointer call in a reviewed caller) is RESOLVE_STALE
#   and the verdict is INCOMPLETE until the line is re-reviewed.  Every callee must exist in an ELF
#   that has the caller (a renamed clone would otherwise drop out silently); write ?name for a
#   callee that legitimately exists in some flavours only.
#          !prune  NAME                 # evidence      (NAME's subtree is not summed; the
#                                                          raw bound without prunes is always printed)
# A caller absent from an ELF (flavour) is skipped; an absent callee is skipped.
# Every line must carry its evidence.  Re-review when the cited code changes.
